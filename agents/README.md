# Contexto compartilhado — sob demanda

Respeite AGENTS e a política determinística atual. Estes perfis não ampliam permissões nem comprovam execução de modelo. Marketing/gestão: pt-BR.

Identifique tarefa/repo → resumo relevante → domínio → arquivos/trechos necessários. Não recarregue contexto já presente no handoff. Arquitetura/responsabilidades: seção pertinente de [agent-design.md](../docs/agent-design.md); dados: [data-model.md](../docs/data-model.md). Não leia todos os guias.

Delegação: uma subtask independente por responsável, com objetivo, revisão, arquivos/campos, restrições, evidências e saída esperada. Orquestrador integra e revisa; contagem/CSV fica nas ferramentas determinísticas.

Antes de salvar conhecimento, procure a fonte existente. GLOBAL: orientação do usuário fora do repo; REPOSITORY: documentação central; DOMAIN: seção da área; AGENT: regra exclusiva do papel; TEMPORARY: somente handoff. Não persistir segredos, transcrições ou logs em prompts. Evidência bruta fica no registro apropriado; dados de exemplo não são evidência comercial.
